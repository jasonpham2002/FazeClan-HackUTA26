# Player portraits

Put approved player images here, named by player ID (for example `player_frozen.webp`), then list each one with its credit in `APPROVED_PORTRAITS` in `src/api/fixtures/players.sample.ts`. In live mode the image URL comes from Johnny's `Player.imageUrl` instead.

Only add an image when FaZe Clan, the photographer or the event organiser has cleared it for this project, and record the credit. Transparent PNG or WebP cut-outs (about 900 x 1500 px, the player framed from the waist up) look best in the lineup. Anything missing or failing to load falls back to the silhouette.
